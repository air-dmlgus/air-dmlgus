# Fair Duty Scheduler | 데이터 기반 근무표 자동 배정

가위바위보로 정하던 야간 근무 시간대를 **시간대별 체감 피로도와 개인별 누적 부담**을 기준으로 배정하는 Python 포트폴리오 예제입니다.

> **코드 출처:** 군 복무 중 개발·배포했던 근무표 프로그램의 경험을 바탕으로 **새로 작성한 재구현 예제**입니다. 실제 부대에서 사용한 원본 소스코드나 설문 원자료가 아니며, 예제 가중치는 설명용 가상 수치입니다.

## 배경과 문제

의무경찰 복무 중 근무 시간대를 가위바위보로 배정하면서 일부 대원이 부담이 큰 시간대에 반복 배정되는 문제가 있었습니다. 이를 개선하기 위해 Python을 독학하고, 소대원 **15명 대상 시범 조사**를 거쳐 **중대원 약 60명**으로 설문 범위를 확대했습니다. 시간대별 피로도를 가중치로 수치화하고 한 달 치 근무표를 자동 생성하는 방식으로 개선했습니다. 휴가 등 근무 불가능 일정도 사전에 반영했습니다. 실제 프로그램은 지휘관 허락을 받아 배포되었고, 이후 전출한 다른 부대에서도 채택되었습니다.

## 이 저장소의 구현 범위

- 20:00~익일 08:00까지 **1시간 단위 12개 근무 슬롯** 생성
- 시간대별 피로도 가중치 적용 (예제값이며 실제 설문 결과 아님)
- 누적 피로도와 근무 횟수를 고려한 균형 배정
- 휴가·개인 일정에 따른 **날짜별 배정 제외**
- 동일 야간 근무 내 중복 배정 방지(인원 부족 시 오류)
- 월간 CSV 출력 및 개인별 배정 횟수·피로도 요약

**가정:** 한 시간대에 1명 근무, 한 사람은 같은 야간 근무에서 최대 1회 배정됩니다. 실제 부대의 운영 규칙과 다를 수 있습니다.

## 실행

Python 3.10+ / 외부 패키지 불필요

```bash
python scheduler.py --year 2026 --month 11 --people 60 --output schedule.csv
python -m unittest discover -s tests -v
```

휴가자 등 제외 일정은 `--unavailable unavailable.json`으로 전달합니다.

```json
{
  "2026-11-03": ["P001", "P002"],
  "2026-11-04": ["P005"]
}
```

`2026-11-03`은 **20:00에 시작하는 야간 근무**를 뜻합니다. 예제 인원 ID는 P001~P060이며, 실제 인적사항은 포함하지 않습니다.

## 핵심 로직

각 슬롯마다 **배정 후 예상 누적 피로도**가 가장 낮은 근무 가능 인원을 선택합니다. 동점이면 배정 횟수와 순환 순서를 고려합니다. 전체 최적해를 보장하는 수학적 최적화 알고리즘이 아니라, 설명과 검증이 쉬운 **탐욕적 휴리스틱**입니다.
